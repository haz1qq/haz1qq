## Open source

**[myuni-api](https://github.com/haz1qq/myuni-api)** — an open-source REST API for Malaysian higher-education data: public and private universities, polytechnics, community colleges, Mara colleges, and their campuses. Express and TypeScript with Zod validation and Swagger/OpenAPI docs, plus a searchable map landing page. Live at [myuni-api.my](https://www.myuni-api.my/).

**[ellie](https://github.com/haz1qq/ellie)** — a local-first Windows tray app being developed to help track AI quota, with a quiet black-and-white cat personality. Built with Tauri, Rust, React, and TypeScript. Milestone 0 (the app shell) is complete and passed Windows smoke testing; provider integrations are the next step.

## Private projects

Selected projects with private source code:

**JomHadir** — a QR-code event attendance and guest-management platform for Malaysian events. Organisers create an event, import a guest list from a spreadsheet, and check people in at the door with a printed QR code. Guests install nothing. Private events are verified against the invited list; public events accept walk-ins. Laravel, Inertia, React, and Tailwind.

**report-ai-api** — a PHP project described as an API for a teacher application's AI report feature.

**post-boost** — a drafting workflow where an operator pastes a source link, receives an AI draft written in that account's voice, then approves, edits, schedules, or rejects it before anything is published. Python, with a Telegram interface and an approval-based publishing workflow.
